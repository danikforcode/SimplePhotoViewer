# SimplePhotoViewer 0.0.6-alpha (Rust / Win32)

Лёгкий универсальный просмотрщик: фото, PDF, документы, таблицы, тексты и код,
аудио и видео. Правка фото, коллаж, склейка PDF, печать, пакетная конвертация.
Один exe без внешних DLL (только системные), **≈2,4 МБ** (бюджет — 10 МБ).

Лицензия: GNU GPL v3 или новее. © 2026 Даниил Кочубейник.

## Сборка (на Windows)

1. Установить Rust 1.88 или новее: https://rustup.rs (при установке согласиться на MSVC Build Tools).
2. В папке проекта: `cargo build --release` (или запустить `build.bat`).
3. Готово: `target\release\simple_photo_viewer.exe`.

Тесты чистой логики (геометрия, цвет, раскладки, PDF, RTF из DOCX/ODT/Markdown, CSV и
сортировка таблиц, кодировки текста, подсветка синтаксиса, свои декодеры TGA/PNM/QOI): `cargo test`.

## Что открывает

| Тип | Форматы | Что можно |
|---|---|---|
| Фото | JPEG, PNG, BMP, GIF, TIFF, ICO, JPEG XR, DDS (WIC); HEIC, WebP, AVIF, RAW — если в Windows стоят расширения кодеков; TGA, PNM/PPM/PGM/PBM, QOI — свои декодеры | правки, печать, коллаж, в PDF, конвертация |
| PDF | любые (Windows.Data.Pdf, Windows 10/11) | листать, вставлять/удалять/переставлять страницы, поворот без потерь, склейка |
| Документы | DOCX, DOCM, DOTX, ODT, RTF, Markdown | **только просмотр**: «Книга» (по странице) или «Прокрутка» (лентой); печать, в PDF |
| Таблицы | XLSX, XLSM, XLSB, XLS, ODS, CSV, TSV | **только просмотр**: листы, закреплённый заголовок, сортировка щелчком по столбцу ▲ ▼ (файл не меняется), ширина столбцов, копирование ячейки/строки |
| Текст и код | TXT, LOG, INI, CFG, JSON, YAML, TOML, XML, HTML, CSS, JS/TS, PY, RS, C/C++, C#, Java, Go, Kotlin, PHP, SQL, BAT, PS1, SH, MD… | правка «как в Блокноте» + подсветка синтаксиса, поиск и замена, перенос строк, кодировка (UTF-8/UTF-16/1251) и концы строк сохраняются |
| Аудио | MP3, M4A/AAC, WAV, FLAC, WMA, OGG/Opus*, AIFF, AC3, AMR… | плеер: волна, перемотка, громкость, повтор, скорость 0,5–2× |
| Видео | MP4, MOV, M4V, AVI, WMV, MKV*, WebM*, 3GP, TS/MTS, MPG… | плеер, кадр → фото, во весь экран |

\* зависит от кодеков Windows: HEVC, VP9, AV1, Web Media Extensions ставятся из Microsoft Store.

## Конвертация (Ctrl+E, «Создать → Конвертировать»)

Сразу много файлов (кнопка «Добавить…» с множественным выбором или перетаскивание файлов и папок):

- фото → JPEG, PNG, BMP, TIFF, GIF, JPEG XR, ICO, PDF; можно уменьшить по длинной стороне;
- аудио → MP3, AAC (M4A), WAV, FLAC, WMA;
- видео → MP4 (H.264 + AAC), WMV, или только звук в MP3/AAC; можно уменьшить до 1080p/720p/480p;
- качество: высокое / среднее / меньше файл; результат — рядом с исходниками или в выбранную папку;
  существующие файлы не перезаписываются (добавляется « (1)»).

Показываются только настройки для тех типов, что есть в списке.

## Печать

Своё окно (Ctrl+P): принтер и его свойства, бумага, ориентация, 1/2/4/6/9 фото на листе,
вписать/заполнить, автоповорот, поля, копии, правки «только для печати», «Сохранить в PDF».

Шаблон задаёт начальное место, а дальше **каждое фото на листе можно поправить вручную**:
щелчок — выбрать; тянуть — двигать (Shift — строго по горизонтали/вертикали); уголки — размер;
кружок сверху — повернуть на любой угол (прилипает к 0/90/180°, с Shift — шаг 15°).
Клавиши: стрелки — сдвиг на 1 мм (Shift — 5 мм), + / − — размер, [ ] — поворот на 1° (Shift — 15°),
Delete или двойной щелчок — сбросить. Кнопки под предпросмотром: ↺ ↻ на 90°, меньше/больше,
на место, сброс. Печать и PDF — ровно как на предпросмотре.

## Два режима: обзор и работа

- **Обзор** (всегда при открытии): ← → листают файлы папки, по краям видны «хвостики» соседей,
  лента и панель подстраиваются под тип файла. Колесо — масштаб (или прокрутка ленты страниц).
- **Работа** — у документов (PDF, DOCX, ODT, RTF, Markdown), текстов и таблиц. Вход: кнопка слева
  внизу и первая на ленте — «Читать», «Править» или «Работать» (по типу файла), либо Enter;
  у текста — щелчок по тексту или любая буква, у таблицы — щелчок по ячейке, у документа —
  двойной щелчок. Над холстом появляется полоса акцентного цвета, хвостики прячутся.
  - документ: ← → PgUp PgDn — страницы, Home/End — начало/конец (в «Прокрутке» ↑ ↓ — плавно);
  - текст: обычная правка с курсором, поиск и замена;
  - таблица: стрелки ходят по ячейкам, сортировка, копирование.
- Выход — Esc или кнопка «К файлам». Alt+← / Alt+→ и Ctrl+PgUp / Ctrl+PgDn — соседний файл
  из любого режима.
- Фото и медиа всегда в обзоре: ← → — файлы; у медиа пробел — пуск/пауза, Shift+← → — перемотка на 5 с.

## Интерфейс

- **Хвостики**: по краям окна виден кусочек соседнего файла (или соседней страницы) — фото,
  первая страница PDF, кадр видео, волна звука, первые строки текста, ячейки таблицы.
  Нет хвостика — нет соседа. Наведение — хвостик выезжает и показывает имя, щелчок — переход.
- Перелистывание фото и страниц — с короткой анимацией сдвига.
- **Адаптивная лента и панель**: у каждого типа файла свои вкладки и кнопки; в узком окне
  подписи прячутся (остаются значки), лишнее уходит в «…», нижняя панель убирает второстепенное.
- Тема: светлая / тёмная / как в системе. Положение окна и настройки запоминаются.

Клавиши — F1 в программе. Главное: ← → — соседний файл (в работе — страница); Enter / Esc — работа / обзор; Ctrl+W — закрыть файл; пробел — пуск/пауза; Ctrl+F / F3 / Ctrl+H — поиск и замена.

## Почему так мало весит

- Декодеры картинок, PDF, разметка документов, аудио/видео-кодеки и плеер — системные
  компоненты Windows (WIC, Windows.Data.Pdf, RichEdit, Media Foundation): 0 байт в exe.
- Интерфейс рисуется через GDI самим приложением; значки — глифы шрифта Segoe MDL2 Assets.
- Сторонние библиотеки: lopdf (запись PDF), calamine (Excel/ODS), zip + quick-xml (DOCX/ODT),
  pulldown-cmark (Markdown) — все MIT/Apache.
- Профиль release: `opt-level = "z"`, LTO, `panic = "abort"`, `strip`.

## Ограничения alpha-версии

- Документы показываются так, как их разметит системный RichEdit: простое оформление, заголовки,
  списки, таблицы и картинки — да; колонтитулы, сноски, сложная вёрстка — упрощённо или нет.
- Таблицы — только просмотр; формулы показываются результатом, сохранённым в файле.
- Набор аудио/видео-форматов зависит от установленных в Windows кодеков.
- Конвертация видео: одна звуковая дорожка, субтитры не переносятся.
- Очень большие тексты (больше ~3 МБ) открываются без подсветки.
- PDF с паролем на открытие не поддерживаются.
- Стандартные окна Windows (выбор файла, сообщения) следуют системной теме.
- Правки (обрезка, цвет, размер) превращают страницу PDF в картинку; поворот качество не меняет.
