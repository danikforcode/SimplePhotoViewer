# SimplePhotoViewer 0.0.3-alpha (Rust / Win32)

Лёгкий просмотрщик фото и PDF: быстрые правки, коллаж, склейка PDF, печать
с предпросмотром. Один exe без внешних DLL (только системные), **≈1,3 МБ**.

Лицензия: GNU GPL v3 или новее. © 2026 Даниил Кочубейник.

## Сборка (на Windows)

1. Установить Rust 1.88 или новее: https://rustup.rs (при установке согласиться на MSVC Build Tools).
2. В папке проекта: `cargo build --release` (или запустить `build.bat`).
3. Готово: `target\release\simple_photo_viewer.exe`.

Тесты чистой логики (геометрия, цвет против эталона PIL, раскладки коллажа и листа печати,
сборка и склейка PDF, буфер обмена): `cargo test`.

## Что умеет

| | |
|---|---|
| Открытие | Ctrl+O (можно выбрать несколько файлов), перетаскивание в окно, аргументы командной строки, Ctrl+V |
| Форматы | JPEG, PNG, BMP, GIF, TIFF (кодеки Windows, WIC); HEIC/WebP — если в системе стоят расширения; **PDF** |
| PDF | просмотр встроенным модулем Windows 10/11 (Windows.Data.Pdf); листание страниц, масштаб |
| Документ | любой набор фото и страниц PDF: вставить (Ctrl+I), удалить (Delete), переставить, повернуть страницу |
| Склейка PDF | «Объединить в PDF» (Ctrl+M): фото и PDF по порядку → один PDF. Страницы PDF — **без потери качества** (текст остаётся текстом); фото — на лист A4 с полями или «по размеру фото» |
| Коллаж | Ctrl+G: сетка, крупное слева/сверху, в ряд, в столбик; холст A4, 10×15, квадрат, 16:9 или «по фото»; отступы, фон, заполнить/вписать; живой предпросмотр |
| Правки | поворот, отражение, обрезка (Ctrl+K), яркость/контраст/насыщенность, Ч/Б, размер (½, 1920 px), отмена (10 шагов) |
| Печать | своё окно (Ctrl+P): предпросмотр листа, выбор принтера и его свойства, бумага, ориентация (авто), 1/2/4/6/9 фото на листе, вписать/заполнить, автоповорот, поля, копии, правки «только для печати», «Сохранить в PDF» как на предпросмотре |
| Интерфейс | шапка-лента с вкладками (Главная, Правка, Страницы, Создать, Вид), нижняя панель быстрых инструментов, подсказки, строка состояния |
| Тема | светлая / тёмная / как в системе — во всех окнах программы, включая заголовок окна |
| Прочее | Ctrl+C — копировать картинку; F11 — во весь экран; положение окна и настройки запоминаются |

### Нижняя панель

◀ ▶ (фото или страница) · − / вставка фото/страницы / вписать / 100% / + · поворот ↺ ↻ · обрезка · отмена · печать ·
справа — размер изображения, масштаб и номер страницы.

## Структура

```
src/main.rs        точка входа, перехват паники → %APPDATA%\SimplePhotoViewer\error.log
src/gui.rs         мини-набор «самонарисованных» элементов (кнопки, вкладки, списки…) и окно-хозяин
src/theme.rs       светлая/тёмная тема, тёмный заголовок окна (DWM)
src/ui.rs          главное окно: лента, холст, нижняя панель, команды
src/doc.rs         документ = список страниц (фото / страница PDF / картинка в памяти)
src/pdf_read.rs    просмотр PDF через Windows.Data.Pdf (фоновый поток)
src/pdf_write.rs   сборка/склейка PDF (lopdf) + тесты
src/collage.rs     раскладки коллажа (чистая логика + тесты) и окно коллажа
src/merge.rs       окно «Объединить в PDF»
src/print_dlg.rs   окно печати: предпросмотр, принтер, бумага, N на листе, PDF
src/image_buf.rs   BGRA-буфер: поворот, обрезка, цвет, EXIF (чистая логика + тесты)
src/codec.rs       WIC: чтение, запись, JPEG в память, масштабирование
src/clip.rs        буфер обмена (картинка и файлы из Проводника)
src/files.rs       диалоги открытия/сохранения, список файлов папки
src/settings.rs    настройки в %APPDATA%\SimplePhotoViewer\settings.ini
src/util.rs        мелкие помощники Win32
assets/            иконка, манифест (DPI, Common Controls v6), app.rc (+ сведения о версии)
build.rs           вшивает ресурсы в exe
```

## Почему так мало весит

- Декодеры картинок и просмотр PDF — системные (WIC и Windows.Data.Pdf), в exe их нет.
- Интерфейс рисуется через GDI самим приложением — никаких GUI-фреймворков.
- Значки — глифы системного шрифта Segoe MDL2 Assets (0 байт в exe).
- Единственная сторонняя библиотека — lopdf (MIT), только для записи и склейки PDF (~0,9 МБ).
- Профиль release: `opt-level = "z"`, LTO, `panic = "abort"`, `strip`.

## Ограничения alpha-версии

- Просмотр PDF требует Windows 10/11. Без него PDF всё равно можно склеивать и сохранять, но не показывать.
- PDF с паролем на открытие не поддерживаются.
- Стандартные окна Windows (выбор файла, сообщения, меню выбора принтера) следуют системной теме, а не теме программы.
- Правки (обрезка, цвет, размер) превращают страницу PDF в картинку; поворот страницы PDF качество не меняет.
