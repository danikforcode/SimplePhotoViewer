# SimplePhotoViewer 0.0.9-alpha (Rust / Win32)

Лёгкий универсальный просмотрщик: фото, PDF, документы, таблицы, тексты и код,
аудио и видео. Правка фото, холст для рисования и коллажей, склейка PDF, печать,
пакетная конвертация. Один exe без внешних DLL (только системные), **≈5,9 МБ** (бюджет — 10 МБ).
HEIC, AVIF, WebP, RAW и видео H.265 открываются и там, где в Windows нет кодеков Microsoft:
декодеры встроены (на чистом Rust).

Лицензия MIT (файл LICENSE). © 2026 danikforcode. Сторонние компоненты и их лицензии —
THIRD-PARTY.md (то же — в программе: «О программе → Лицензии»).

## Сборка (на Windows)

1. Установить Rust 1.90 или новее: https://rustup.rs (при установке согласиться на MSVC Build Tools).
2. В папке проекта запустить `build.bat`. Он собирает две части по очереди:
   `cargo build --release -p spv_thumbs` (DLL миниатюр для Проводника, папка `thumbs/`) и
   `cargo build --release -p simple_photo_viewer` (программа; DLL вшивается в exe сжатой).
   Если собрать только программу (`cargo build --release`) — всё работает, но без миниатюр
   в Проводнике (сборка предупредит).
3. Готово: `target\release\simple_photo_viewer.exe` — один файл, DLL отдельно носить не нужно.

Тесты чистой логики (геометрия, цвет, раскладки, PDF, RTF из DOCX/ODT/Markdown, CSV и
сортировка таблиц, кодировки текста, подсветка синтаксиса, свои декодеры TGA/PNM/QOI): `cargo test`.

|---|---|---|
| Фото | JPEG, PNG, BMP, GIF, TIFF, ICO, JPEG XR, DDS (WIC); **HEIC/HEIF, AVIF, WebP, RAW** (CR2, CR3, NEF, ARW, DNG, ORF, RW2, RAF, PEF…) — системным кодеком, а если его нет — встроенным; TGA, PNM/PPM/PGM/PBM, QOI — свои | правки, печать, коллаж, в PDF, конвертация; запись WebP (без потерь) |

| Документы | DOCX, DOCM, DOTX, ODT, RTF, Markdown | **только просмотр**: «Книга» (по странице) или «Прокрутка» (лентой); печать, в PDF |
| Таблицы | XLSX, XLSM, XLSB, XLS, ODS, CSV, TSV | **только просмотр**: листы, закреплённый заголовок, сортировка щелчком по столбцу ▲ ▼ (файл не меняется), ширина столбцов, копирование ячейки/строки |
| Текст и код | TXT, LOG, INI, CFG, JSON, YAML, TOML, XML, HTML, CSS, JS/TS, PY, RS, C/C++, C#, Java, Go, Kotlin, PHP, SQL, BAT, PS1, SH, MD… | правка «как в Блокноте» + подсветка синтаксиса, поиск и замена, перенос строк, кодировка (UTF-8/UTF-16/1251) и концы строк сохраняются |

## Встроенные декодеры (когда в Windows нет кодека)

Всегда сначала пробуется системный кодек (он быстрее и точнее); свой — только если система не смогла.

- **HEIC/HEIF** (фото iPhone и Android): heic-decoder — сетки плиток, 8/10 бит, прозрачность,
  поворот/отражение/обрезка из файла. 12 Мп — около секунды.
- **AVIF**: свой разбор контейнера + rav1d (dav1d на Rust) — 8/10/12 бит, 4:2:0/4:2:2/4:4:4,
  сетки, прозрачность, поворот.
- **WebP**: image-webp (с потерями, без потерь, прозрачность; у анимации — первый кадр).
- **RAW**: встроенный в снимок полноразмерный JPEG (так делают и камеры при просмотре);
  если системный RAW-кодек есть («Raw Image Extension») и даёт снимок не меньше — берётся он.
- **Видео H.265 в MP4/MOV**: свой проигрыватель — разбор MP4 (поворот из файла учитывается),
  декодер rusty_h265, звук AAC — системный (Media Foundation), часы — по звуку. Перемотка,
  пауза, громкость, «кадр → фото». Если процессор не успевает (4K на слабом ПК): со звуком
  лишние кадры пропускаются, без звука видео идёт медленнее, но без рывков. Скорость — только 1×.
- Проверить, чем открывается файл: `SimplePhotoViewer.exe --probe файл…`.

## Программа по умолчанию и миниатюры в Проводнике («Вид → По умолчанию»)

- «Сделать по умолчанию…» — регистрирует типы файлов (только для вас, без прав администратора)
  и открывает «Параметры → Приложения по умолчанию»: Windows разрешает выбрать программу
  по умолчанию только самому пользователю. «Только миниатюры» — то же без «Параметров».
- **Миниатюры остаются**: вместе с программой регистрируется обработчик миниатюр (DLL кладётся
  в `%LOCALAPPDATA%\SimplePhotoViewer\Explorer`). Для каждого файла он сначала зовёт системный
  обработчик этого типа (как было бы с «Фотографиями»), а если его нет или он не справился —
  делает миниатюру сам: HEIC, AVIF, WebP, RAW, первая страница PDF, кадр HEVC-видео.
  Значки и окно предпросмотра типов файлов берутся у прежних системных типов.
- Если программу перенесли в другую папку или обновили — записи обновятся сами при запуске.
- «Убрать из системы» — удаляет всё записанное; типы файлов возвращаются к прежним программам.
- Проверить DLL без Проводника: `SimplePhotoViewer.exe --thumb файл…` (рядом появится *.thumb.png).

## Конвертация (Ctrl+E, «Создать → Конвертировать»)

Сразу много файлов (кнопка «Добавить…» с множественным выбором или перетаскивание файлов и папок):

- фото → JPEG, PNG, BMP, TIFF, GIF, JPEG XR, ICO, PDF; можно уменьшить по длинной стороне;
- аудио → MP3, AAC (M4A), WAV, FLAC, WMA;
- видео → MP4 (H.264 + AAC), WMV, или только звук в MP3/AAC; можно уменьшить до 1080p/720p/480p;
- качество: высокое / среднее / меньше файл; результат — рядом с исходниками или в выбранную папку;
  существующие файлы не перезаписываются (добавляется « (1)»).

Показываются только настройки для тех типов, что есть в списке.

## Правка фото («Править» → вкладки «Правка» и «Рисование»)

- **Выделение**: рамка, овал, лассо, волшебная палочка (допуск, «смежные»); Shift — добавить,
  Alt — вычесть (или кнопки «Новое / Добавить / Вычесть»), «Обратить» — например, выделить фон.
  Ctrl+A — всё, Ctrl+D — снять, Delete — залить выделенное белым, Ctrl+C — копировать выделенное.
  Снаружи выделения фото затемнено, край — пунктиром.
- **Настройка** — панель ползунков с живым просмотром: яркость, экспозиция, контраст, светлые,
  тени, насыщенность, теплота, оттенок, резкость, размытие, виньетка. Двойной щелчок по ползунку — ноль.
- **Эффекты** одним щелчком: Ч/Б, сепия, негатив, размытие, резкость, пиксели (скрыть номер или лицо).
  Всё это ложится на выделенное, а если ничего не выделено — на всё фото.
- **Обрезка** с пропорциями: свободно, исходные, 1:1, 4:3, 3:2, 16:9, A4, кнопка «повернуть рамку»;
  рамку можно двигать. Если есть выделение — «Обрезать» режет сразу по нему.
- **Размер и формат** (Ctrl+Shift+R) — как в «Фотографиях»: размер в точках или процентах с замком
  пропорций, готовые размеры, тип файла (JPEG, PNG, BMP, TIFF, GIF, JPEG XR, HEIC), качество,
  разрешение для печати (DPI) с подсказкой «на бумаге — столько-то см». «Сохранить копию»
  не трогает открытое фото, «Применить к фото» меняет его (Ctrl+Z — отменить).
- **Рисование**: карандаш, маркер-выделитель, ластик (стирает штрих целиком), линия, стрелка, рамка,
  овал (с заливкой), текст; 10 цветов + любой, 4 толщины, непрозрачность. Shift — ровно (45°,
  квадрат, круг). Пока рисуете, всё можно отменять (Ctrl+Z) и стирать; «Готово», Esc, переход
  к другому файлу или сохранение — «впечатывают» рисунок в фото.

## Холст и коллаж («Создать → Холст», Ctrl+N; «Коллаж», Ctrl+G)

Один инструмент «и так и сяк»: чистый лист, как в Paint, и на нём — фото-объекты и рисунок.

- **Формат холста**: 16:9 (3840 × 2160), Full HD, 4:3, квадрат, A4 и 10 × 15 (300 dpi), сторис 9:16,
  обложка — или «Свой…» в точках; фон — 8 цветов. Смена формата сохраняет раскладку пропорционально.
- **Фото как объекты**: «Добавить фото…», перетаскивание файлов в окно, Ctrl+V из буфера.
  Щелчок — выбрать; тянуть — двигать; **углы** — размер (без искажений); **края** — обрезка рамкой
  (фото не растягивается); **кружок** сверху — поворот на любой угол (прилипает к 0/90°, Shift — шаг 15°);
  Ctrl+тянуть — сдвинуть фото внутри рамки; колесо над фото — размер; двойной щелчок — «ровно».
  Кнопки: выше/ниже других (Page Up / Page Down), на 90°, ровно, копия (Ctrl+D), убрать (Delete);
  стрелки — сдвиг (Shift — крупнее).
- **Шаблоны коллажа**: сетка, крупное слева, крупное сверху, в ряд, в столбик; отступы;
  «Заполнить» (фото обрезается по ячейке) или «Вписать» (целиком). Шаблон только раскладывает —
  после него каждое фото можно двигать, крутить и обрезать как угодно. «Коллаж» открывает холст
  сразу с открытыми фото, разложенными по шаблону.
- **Рисование поверх**: карандаш, маркер, ластик, линия, стрелка, рамка, овал (с заливкой), текст;
  10 цветов, 5 толщин. Нарисованное позже лежит поверх фото, добавленных раньше.
- Ctrl+Z — отменить (60 шагов). «Готово» — холст становится открытой картинкой (дальше — правка,
  печать, PDF, «Размер и формат»); «Сохранить как…» — сразу в файл (JPEG, PNG, PDF…).
  Экран и итог рисует один и тот же GDI+, поэтому в файле — ровно то, что на холсте.

## Печать

Своё окно (Ctrl+P): принтер и его свойства, бумага, ориентация, 1/2/4/6/9 фото на листе,
вписать/заполнить, автоповорот, поля, копии, правки «только для печати», «Сохранить в PDF».

**Формат листа**: A4, A5, A3, Letter, размер принтера — и «Другой формат»: слайд 16:9
(338,7 × 190,5 мм) и 4:3, квадрат, фото 10 × 15 и 13 × 18, A6, A2, «по размеру фото» (без полей)
и свой размер в мм. В PDF лист получается ровно такого размера; принтеру уходит запрос
нестандартной бумаги (если драйвер его не поддерживает, печать идёт на его ближайший формат).

Шаблон задаёт начальное место, а дальше **каждое фото на листе можно поправить вручную**:
щелчок — выбрать; тянуть — двигать (Shift — строго по горизонтали/вертикали); уголки — размер;
кружок сверху — повернуть на любой угол (прилипает к 0/90/180°, с Shift — шаг 15°).
Клавиши: стрелки — сдвиг на 1 мм (Shift — 5 мм), + / − — размер, [ ] — поворот на 1° (Shift — 15°),
Delete или двойной щелчок — сбросить. Кнопки под предпросмотром: ↺ ↻ на 90°, меньше/больше,
на место, сброс. Печать и PDF — ровно как на предпросмотре.

## Два режима: обзор и работа

- **Обзор** (всегда при открытии): ← → листают файлы папки, по краям видны «хвостики» соседей,
  лента и панель подстраиваются под тип файла. Колесо — масштаб (или прокрутка ленты страниц).
- **Работа** — у документов (PDF, DOCX, ODT, RTF, Markdown), текстов и таблиц. Вход: кнопка слева
  внизу и первая на ленте — «Читать», «Править» или «Работать» (по типу файла), либо Enter;
  у текста — щелчок по тексту или любая буква, у таблицы — щелчок по ячейке, у документа —
  двойной щелчок. Над холстом появляется полоса акцентного цвета, хвостики прячутся.
  - документ: ← → PgUp PgDn — страницы, Home/End — начало/конец (в «Прокрутке» ↑ ↓ — плавно);
  - текст: обычная правка с курсором, поиск и замена;
  - таблица: стрелки ходят по ячейкам, сортировка, копирование.
- Большой PDF листается без задержек: страницы рисуются в фоне (два потока, «последний запрос —
  первым»): при быстрой прокрутке рисуются только видимые страницы, сначала грубый набросок,
  затем точная; соседние страницы готовятся заранее. Окно при этом не ждёт отрисовки.
- Выход — Esc или кнопка «К файлам». Alt+← / Alt+→ и Ctrl+PgUp / Ctrl+PgDn — соседний файл
  из любого режима.
- Фото: «Править» (или Enter) — правка и рисование, см. выше.
- Медиа всегда в обзоре: ← → — файлы; пробел — пуск/пауза, Shift+← → — перемотка на 5 с.

## Интерфейс

- **Хвостики**: по краям окна виден кусочек соседнего файла (или соседней страницы) — фото,
  первая страница PDF, кадр видео, волна звука, первые строки текста, ячейки таблицы.
  Нет хвостика — нет соседа. Наведение — хвостик выезжает и показывает имя, щелчок — переход.
- Перелистывание фото и страниц — с короткой анимацией сдвига.
- **Адаптивная лента и панель**: у каждого типа файла свои вкладки и кнопки; в узком окне
  подписи прячутся (остаются значки), лишнее уходит в «…», нижняя панель убирает второстепенное.
- Все окна программы — свои, в её теме: вопросы («Сохранить / Не сохранять / Отмена»),
  сообщения, «Горячие клавиши» (таблица по разделам), выбор цвета (поле тон/насыщенность,
  палитра, недавние, #RRGGBB), «О программе» и «Лицензии». Системные остались только окна
  выбора файла и свойства принтера.
- Справа вверху — «Горячие клавиши» и «Во весь экран» (F11); в полном экране у верхнего края
  появляется кнопка «Выйти». Тема (светлая / тёмная / как в системе) — во вкладке «Вид».
  Положение окна и настройки запоминаются.

Клавиши — F1 в программе. Главное: ← → — соседний файл (в работе — страница); Enter / Esc — работа / обзор; Ctrl+W — закрыть файл; пробел — пуск/пауза; Ctrl+F / F3 / Ctrl+H — поиск и замена.

```
assets/            иконка, манифест, app.rc (+ сведения о версии)
```

## Замеры и нагрузочная проверка

Без окна, отчёт — в консоль (если запущено из неё) и в файл:

```
SimplePhotoViewer.exe --bench  [отчёт.txt]            сколько длятся тяжёлые операции
SimplePhotoViewer.exe --stress [циклов] [отчёт.txt]   циклы «открыть → править → сохранить», поиск утечек
```

`--bench`: JPEG/PNG 24 Мп, миниатюры, поворот, ползунки и эффекты на 24 Мп и на экранной копии,
волшебная палочка, рисунок из 200 фигур, коллаж 8 фото → 4K, PDF на 30 страниц и склейка,
отрисовка страницы PDF, CSV на 100 000 строк и сортировка, подсветка 3 МБ кода, кодировки.
`--stress`: в каждом цикле — правка, эффект в выделении, рисунок, обрезка, поворот, сохранение
по кругу в JPEG/PNG/BMP/TIFF/GIF/WebP и обратное открытие со сверкой размера; каждый 5-й — коллаж,
каждый 10-й — PDF, таблица, подсветка. Следит за памятью и объектами GDI/USER; код выхода 1,
если были ошибки или ресурсы растут. Переменные для отладки: `SPV_TRACE=1` — медленные (> 25 мс)
сообщения окна и итог по памяти при выходе; `SPV_FAKE_PDF=<мс>` — имитация отрисовки PDF там,
где нет Windows.Data.Pdf (Wine).

Тяжёлая обработка пикселей (ползунки, размытие, резкость, виньетка, Ч/Б, сепия) делится
между ядрами процессора.

## Почему так мало весит

- Декодеры картинок, PDF, разметка документов, аудио/видео-кодеки и плеер — системные
  компоненты Windows (WIC, Windows.Data.Pdf, RichEdit, Media Foundation, GDI+): 0 байт в exe.
- Интерфейс рисуется через GDI самим приложением; значки — глифы шрифта Segoe MDL2 Assets.
- Сторонние библиотеки: lopdf (запись PDF), calamine (Excel/ODS), zip + quick-xml (DOCX/ODT),
  pulldown-cmark (Markdown) — MIT/Apache; декодеры heic-decoder, image-webp (MIT/Apache),
  rav1d (BSD), rusty_h265 (Apache 2.0) — около 3 МБ вместе с DLL миниатюр.
- Профиль release: `opt-level = "z"`, LTO, `panic = "abort"`, `strip`; декодеры — `opt-level = 3`
  (вдвое быстрее, +0,3 МБ).

## Ограничения alpha-версии

- Документы показываются так, как их разметит системный RichEdit: простое оформление, заголовки,
  списки, таблицы и картинки — да; колонтитулы, сноски, сложная вёрстка — упрощённо или нет.
- Таблицы — только просмотр; формулы показываются результатом, сохранённым в файле.
- Набор аудио/видео-форматов зависит от установленных в Windows кодеков (кроме HEVC в MP4/MOV).
- Свой проигрыватель HEVC: только MP4/MOV (не MKV/TS), скорость только 1×; цвета — BT.709
  (HDR не преобразуется). 4K на слабом процессоре идёт медленнее реального времени.
- RAW показывается встроенным в снимок JPEG (без своей «проявки» сырых данных); у старых
  камер без такого JPEG (Sigma X3F, Kodak) нужен системный кодек.
- Конвертация видео: одна звуковая дорожка, субтитры не переносятся.
- Очень большие тексты (больше ~3 МБ) открываются без подсветки.
- PDF с паролем на открытие не поддерживаются.
- Окна выбора файла и свойства принтера — системные (следуют теме Windows).
- Правки (обрезка, цвет, размер) превращают страницу PDF в картинку; поворот качество не меняет.
- Выделение «объекта» — вручную или волшебной палочкой по цвету; автоматического распознавания
  объектов (нейросетью) нет — оно не помещается в 10 МБ.
- Нарисованное до «Готово» — отдельные фигуры; после — часть фото (отменяется через Ctrl+Z).
- На холсте нарисованное выбрать и подвинуть нельзя (только стереть ластиком или отменить);
  двигаются и крутятся фото.
